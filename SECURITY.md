# Security Policy

## Supported Versions

We release security updates and bug fixes on the latest version running on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within **Emoji Runner**, please do not report it through public GitHub issues. Instead, please report it privately:

1. Send an email to [amarasekaracharaka2@gmail.com](mailto:amarasekaracharaka2@gmail.com) with the subject line: `[Security] Emoji Runner Vulnerability Report`.
2. Include the following details in your email:
   - A description of the vulnerability.
   - Steps to reproduce or proof-of-concept.
   - Potential impact of the issue.
   - Any suggested mitigations or fixes.

## Response Timeline

- **Acknowledgment**: You will receive an initial response acknowledging your report within 48 hours.
- **Assessment**: The vulnerability will be investigated and triaged within 5 business days.
- **Resolution**: Once verified, a patch will be prepared, tested, and merged to `main` before public disclosure.

Thank you for helping keep Emoji Runner safe and secure for our players!
